# MESA Law MVP Out of Scope

The following features have been actively removed or feature-flagged out of the core MVP iteration. They will not be worked on until the Golden Path is perfectly stable.

- Multi-tenant SaaS optimization and dynamic provisioning
- Advanced billing and subscription management
- Advanced analytics dashboards
- Full-fledged CRM capabilities
- Mobile applications
- Advanced calendar integrations
- Automatic client portal access
- Comprehensive legal database searches (Global research)
- Deep conflict intelligence (automatic resolution)
- Advanced graph visualization (contradiction maps)
- Full-scale support-access compliance portal
- Production SOC 2 placeholder screens
- AI model marketplace

## Action Taken
- Navigation items linking to these features are hidden.
- Placeholder/Mock data generating screens are removed.
- Endpoints serving stubbed data return 404 or are disabled via feature flag.
