# WO-002 — Core Docker profili

## Amaç
MESA-Law projesinin `core` profili altında çalışacak temel bağımlılıklarının (PostgreSQL, MinIO, Redis, Keycloak, ClamAV, Caddy, OTel/Grafana stack ve app servisleri) `docker-compose.yml` dosyasına eklenmesi.

## Ön koşullar
- WO-001 tamamlanmış olmalı.
- Docker ve Docker Compose hazır olmalı.

## İzin verilen repo ve yollar
- `/storage/MESA_Law/` kök dizini (özellikle `docker-compose.yml`)

## Yasak yollar
- `/home/yasin/Desktop/MESA` dizinindeki kaynak kodlara dokunulmamalıdır.

## Değiştirilecek sözleşmeler
- Geliştirme ortamı `docker-compose.yml` üzerinden çalışacaktır.

## Uygulama adımları
1. `/storage/MESA_Law/docker-compose.yml` dosyası oluşturulacak.
2. İstenen servisler (web, legal-api, legal-worker, postgres, redis, minio, keycloak, clamav, caddy, otel-collector, prometheus, grafana, loki, tempo) eklenecek ve `--profile core` ile başlatılacak şekilde profillenecektir.
3. Servislere veri kalıcılığı (volumes) eklenecektir.
4. `docker compose --profile core up -d` ile sistemler başlatılıp kontrol edilecektir.
5. Container'lar durdurulup tekrar başlatılarak volume verisinin korunduğu doğrulanacaktır.
6. `Makefile` içerisindeki `dev-doctor` hedefine docker compose statüsü eklenecektir.

## Kabul kriterleri
- Restart sonrası volume verisi korunuyor mu?
- `make dev-doctor` geçerli mi?

## Çalıştırılacak testler
- `docker compose --profile core up -d`
- `docker compose ps`
- `docker compose down` ve yeniden `up` sonrasında verilerin kalıcı olduğu denetlenecek.
- `make dev-doctor`

## Güvenlik/veri kontrolü
- Secret'lar doğrudan compose içine yazılmayacak, `.env` dosyasından okunması sağlanacak (veya default dev şifreleri belirtilecek).
- Portlar, local'de çalışan diğer servislerle çakışmayacak şekilde (`.env` üzerinden) yapılandırılacak.

## Rollback
- `docker compose down -v` ile containerlar ve volumeler silinir, `docker-compose.yml` silinerek geri dönülür.
