# WO-009 — Frontend Shell ve Canonical Workflow

## Amaç
Kullanıcıların sisteme giriş yapabileceği, dosya (matter) oluşturabileceği, doküman yükleyip durumunu takip edebileceği ve PDF'leri inceleyebileceği React (Next.js) tabanlı arayüzün (shell) kurulması. API entegrasyonu Orval ile sağlanacak, uçtan uca akış Playwright ile test edilecektir.

## Ön Koşullar
- Backend API (`main.py`) temel route'larının tanımlanması.
- OpenAPI şemasının `apps/api` den elde edilmesi.

## İzin Verilen Repo ve Yollar
- `apps/api/main.py` (Temel router'lar)
- `apps/web/` (Frontend)
- `orval.config.js`

## Değiştirilecek Sözleşmeler
- **API Client:** `apps/web/src/api` dizini altında Orval kullanılarak otomatik üretilecek.
- **Frontend Akışı:** Login -> Matter List/Create -> Upload Document -> Document Viewer.
- **Test:** Playwright ile temel E2E akışının (Mock auth ile giriş yapıp matter yaratma) başarılı olması.

## Uygulama Adımları
1. **API Router:** `apps/api/main.py` içerisinde `matters` ve `documents` için temel CRUD endpoint'leri yazılacak.
2. **OpenAPI Export:** FastAPI üzerinden `openapi.json` dışarı aktarılacak.
3. **Orval:** `apps/web` içerisinde Orval çalıştırılarak React Query hook'ları (veya fetch client'ları) oluşturulacak.
4. **UI Geliştirme:** Next.js App Router veya Pages kullanılarak sayfalar tasarlanacak (Matter List, Matter Detail, Upload).
5. **Playwright:** E2E testleri yazılıp çalıştırılacak.

## Kabul Kriterleri
- Playwright E2E testi: login -> matter oluşturma -> mock upload intent -> belge görüntüleme akışını başarılı şekilde geçmelidir. MESA yapay zeka entegrasyonu olmadan temel "canonical" süreç kanıtlanmış olmalıdır.

## Çalıştırılacak Testler
```bash
cd apps/web && pnpm run test:e2e
```
