# WO-013 — Benchmark governance

## Amaç
Model performansının (retrieval, extraction, citation) değerlendirileceği "gold set" (ground truth) veritabanı tablolarının, split (train/dev/holdout) ayrımının ve sızıntı (leakage) kontrol yapılarının veri modellemesini yapmak.

## Ön Koşullar
WO-012 tamamlandı. (Sadece veritabanı schema/migration ve API taslağı hazırlanacak, veri girişi yapılmayacak).

## İzin verilen yollar
- `apps/api/models/benchmark.py`
- `alembic/versions/`

## Yasak yollar
- `Desktop/MESA`

## Uygulama Adımları
1. **Veritabanı Modelleri (`apps/api/models/benchmark.py`)**:
   - `BenchmarkDataset`: ID, versiyon, domain (legal vs).
   - `BenchmarkItem`: Soru veya görev tanımları, `split` türü (train/dev/holdout).
   - `GoldAnnotation`: (Adjudication schema) Doğru cevaplar, beklenen `source/citation` verileri.
2. **Migration**:
   - Modeli `__init__.py`'a eklemek.
   - Alembic ile tabloyu oluşturmak.

## Kabul Kriterleri
- Değerlendirme tabloları migration'da mevcuttur.
- Benchmark ID/versiyon yapıları hazırdır.
- (Veri oluşturulmayacak, schema ve API taslağı yetiyor).

## Çalıştırılacak Testler
- Migration komutunun hatasız tamamlanması.
